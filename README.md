# 업무 일정 도우미

일일, 주간, 월간 업무를 한 화면에서 관리하는 정적 웹앱입니다. 업무명, 일정 범위, 마감일, 우선순위, 메모를 입력해 일정 보드에 추가할 수 있고 브라우저 `localStorage`에 저장됩니다.

## 실행 방법

별도 빌드 과정 없이 정적 파일을 서빙하면 됩니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 열어 확인하세요.

## 주요 기능

- 일일/주간/월간 컬럼별 업무 분류
- 진행중/완료/전체 필터
- 업무 완료 토글과 삭제
- 브라우저 로컬 저장소 기반 데이터 유지
